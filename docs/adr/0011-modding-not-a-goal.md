# Third-party modding is not a goal; modders get tooling over the fence

The Engine's focus is games and in-house expansions built by the developer. Modders may use the same tooling, but they do not get the game's source, and there is no SDK stability promise for third parties and no sandbox. A sandbox, probably WebAssembly because it is compiled and can be optimized, may be added later but is not a priority. We rejected making modding first-class because it would force a versioned compatibility contract and a trust model before the Engine has a single finished game.
