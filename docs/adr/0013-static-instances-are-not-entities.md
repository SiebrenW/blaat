# Placed items without behavior are Static instances, not Entities, and are promoted when needed

A forest can hold millions of trees, and a village thousands of props. Giving each a full Entity with Components would cost memory and per-Entity bookkeeping that the performance priority and the 2.9 GiB floor GPU cannot afford. Cells therefore store Static instances as packed data (transform, Asset ID, variant) with stable IDs, so Overrides still work. An instance is promoted to a real Entity only when it needs behavior, such as a choppable tree or a pushable crate, so Systems never see the rest. Foliage is a use of Static instances and not a separate type. We rejected render-time scattering with no stored data because the shipped game runs no Procedural rules (ADR 0002) and gameplay and collision could not interact with it.
